# AGRISS

AGRISS (Agriculture Information & Scheduling System) is a full-stack, offline mobile application designed to help small-to-medium farm operators streamline crop care management, harvest tracking, and sales accounting.

## Overview

This project aims to support day-to-day farm operations with tools for:

- Crop care planning and monitoring
- Harvest tracking
- Sales and accounting records
- Offline-friendly mobile workflows for field use

## Features

- Farm activity tracking
- Crop management support
- Harvest record keeping
- Sales accounting overview
- Offline-first experience for remote farm environments

## Getting Started

1. Clone the repository
2. Open the project in your preferred development environment
3. Install dependencies
4. Run the application

## Project Status

This repository is a starting point for the AGRISS application. The project can be expanded with more detailed setup, architecture, and feature documentation as it grows.
